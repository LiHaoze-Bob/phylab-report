# 报告审查

仅在用户主动要求审查、检查或评阅报告时使用。目标是快速找出影响报告可信度或提交的明显问题，默认不逐项复算、不逐句润色，也不做完整排版审计。用户明确要求详细核查时，再按其指定范围深入。

## 简要检查

1. 读取用户指定的最新报告，优先看主要结果、结果表、关键公式、误差分析和结论。结合已有课件、原始记录或计算结果，抽查影响结论的关键项；不为审查重跑全部分析。
2. 留意明显的数量级或单位错误、符号或公式使用错误、正文与表图结果矛盾、结论缺乏数据支持，以及当前教师要求中明显缺失的必要内容。只报告有依据的问题，不把个人写作偏好列成缺陷。
3. 用户提供了示例报告，或本实验资料中有明确标识的示例、参考报告时，做下节的结果比较。没有可用示例时简短说明，不为此联网搜索或扩大查找范围。

只读报告及相关资料，不修改源文件、数据、脚本、图片或已有 PDF，不自动编译、导出或生成审查文件。发现可疑结果时，只做判断所需的少量计算；缺少证据的内容标为待核实。

## 与示例报告比较主要结果

- 先确认两份报告是否属于同一实验，比较的是否为同一物理量；统一单位，核对测量方法、样品、温度、频率、档位等会显著影响结果的条件。条件不同或信息不足时，说明无法直接比较的原因，不直接认定结果错误。
- 重点比较最终测量值、拟合得到的物理参数、主要误差或不确定度及结论方向。不同样品的原始读数、重复次数或正常测量波动不要求一致；示例报告本身也可能有错，不能作为标准答案。
- 差异明显时列出“本报告值、示例值、统一后的单位、差值或倍数”。示例值非零时可用 `|本报告值 − 示例值| / |示例值|` 辅助描述相对差异；示例值为零或接近零时用绝对差或相应物理尺度说明。
- 是否属于“很大差异”，依据本实验的合理范围、课程容差、测量条件和已知不确定度判断，不统一套用固定百分比。数量级不同、方向相反或明显超出合理范围时优先指出；只要证据不足，就写成“差异较大，建议核实”，不要断言错误或编造原因。

## 反馈方式

直接在对话中简短列出问题，优先给出最影响结果或提交的项。每项写清位置、现象和影响，必要时附一句核实方向；区分已确认的问题与待核实的疑点，不提供整份改写稿。

有可比示例时，用一句话或小表说明主要结果是否存在很大差异，并标明示例文件及相关页码或章节；没有示例或不可比时说明限制。未发现明显问题时如实写“本次简要审查未发现明显问题”，不声称已经全面核验。
