# 数据处理与不确定度

先确定测量模型与当前课程要求。以下声速公式仅作通用例子，其他实验按自身模型处理，不复制示例数据或仪器参数。

## 测量、统计与仪器分量

- 从核对后的原始读数计算，保留未修约值；原手算错误不覆盖可靠的原始记录。
- 对独立同精度的重复量，均值的 A 类标准不确定度为 `s/sqrt(n)`。不同频率比或测量方法的组间结果，只有满足统计条件才能直接采用该解释；只用散布评价一致性时说明其范围。
- B 类分量来自仪器允差、分辨率、校准或明确注明的借用参数。用 `Δ/sqrt(3)` 时说明均匀分布，区分允差与已给出的标准不确定度；已给标准不确定度不再除以 `sqrt(3)`。
- 仪器参数不足时给出能评定的分量，不将未知分量设为零或宣称已得到合成不确定度。必要限制用实验记录的语气说明一次。
- 借用另一报告的仪器参数须核对适用条件并明确来源，计算仍使用本次读数。参考报告的实验结果、统计分量或曾经获得的授权不能作为其他作者的默认依据。

原始仪器参数与借用参数分别存储，后者注明来源、数值、单位、适用条件和未计入的分量。

## 声速示例

对12个位置，令 `Δx_i = x_(i+6) - x_i`，`i=1,…,6`：

- 驻波相邻极大间隔 `λ/2`，故 `λ_i = Δx_i/3`。
- 相位同斜率直线间隔 `λ`，故 `λ_i = Δx_i/6`。正、负斜率交替数据先确认换算关系。

声速 `v=f·λ̄`。`1 kHz × 1 mm = 1 m/s`；计算频率贡献 `λ̄·u_f` 时，若 `u_f` 用 Hz，波长换成 m。

在线性且分量独立条件下：

```text
u_A(λ̄) = sqrt(sum((λ_i - λ̄)^2) / (n(n-1)))
u_λ = sqrt(u_A(λ̄)^2 + u_B(λ̄)^2)
u_c(v) = sqrt((λ̄·u_f)^2 + (f·u_λ)^2)
u_c(v)/v = sqrt((u_f/f)^2 + (u_λ/λ̄)^2)
```

若12次位置误差独立同精度，单次标准不确定度为 `u_x`，则 `u_B(λ̄)=q·u_x/(6sqrt(3))`，其中 `q=2` 为驻波、`q=1` 为同斜率相位。共同零点偏移在差值中抵消；标尺比例误差、空程差、漂移等相关分量不直接按独立误差平均，也避免重复计入。

思考题独立给出的仪器精度按题设使用，不转为实际实验参数。

## 修约与结果展示

先核对当前课程的绪论或实验指导，例如 `PPT/绪论.pdf`。下列是可核对的课程规则示例，不替代其他课程的实际要求：

1. 不确定度首位为1或2时保留两位有效数字，首位为3至9时保留一位；检查下一位，非零进位，为零舍去。
2. 测量值按“四舍六入五成双”修约，末位与修约后不确定度对齐。进位改变数量级时重新确定末位，例如 `9.526 → 1×10^1`，测量值相应修约到十位。
3. 相对偏差使用未修约值计算。中间表保留计算位数，最后集中给出修约结果；标清 A 类、拟合统计量或合成标准不确定度。

标准不确定度不直接当作置信区间。标称值不冒充校准真值；仅由组间散布得到的分量不代表总测量不确定度。比较实验与参考结果时考虑参考模型、环境和可能的系统偏差。

## 复核与误差解释

- 用独立计算或等价传播公式核对单位、数据更新与末位修约。时间差和周期共用时基时，检查公共比例误差是否在比值中抵消；有相关性时考虑协方差。
- 区分舍入造成的计算差异、仪器误差和温度、电流等对被测量本身的影响；敏感系数不当作实际误差。
- 异常点没有明确剔除依据时保留并解释；高相关性不替代残差和物理模型检查。
- 将“本组更接近参考值／离散较小”与普遍准确度结论区分。实验探讨提出可验证的复测动作，已在误差分析说明的公式和限制不再展开复述。
