# 预习报告写作与核对

在撰写、补全、修改或评阅预习报告时读取本文件。预习报告说明实验前对原理和方法的理解，以及准备掌握的要点；正式报告的数据处理与实验探讨按主技能执行。

## 先确认本次要求

读取当前课件、教师要求、预习模板和用户最新源文件，确认实验项目、必填栏目、字数限制及是否需要回答思考题。只写用户指定的实验；多项实验是否合并，以当前要求为准。

复用项目现有预习模板，先检查真实导入路径和函数定义。若接口是 `phylab.with(...)`，核对封面参数并在正文填写栏目；若接口是 `physics-prelab-report(info: ..., overview: ..., key-points: ..., difficulties: ...)`，按实际参数传入内容。二者只是可能的接口，不假定模板名称或路径固定，不修改共享模板来适配单份报告。

字数限制以当前模板或教师要求为准。例如有的模板要求综述不超过 500 字、重点与难点各不超过 100 字，这些是上限，不是最低字数，也不推广到其他课程。模板的评分和提交说明用于核对要求，不照抄为报告正文；课程要求上传 PDF 不等于本次编辑任务要求导出 PDF。

## 按栏目组织内容

| 栏目 | 应写内容 |
|---|---|
| 实验综述 | 用自己的话串联实验现象或目标、核心原理、测量关系和计划方法，使读者能看出从哪些读数求得目标量。按需要加入关键公式、光路图或电路图。 |
| 实验重点 | 写本实验要理解的物理关系和要掌握的测量、仪器或数据处理方法，围绕本次实验选择内容。 |
| 实验难点 | 写准备操作时可能难以完成的具体环节，如调节、接线、特征位置判断、读数或误差控制，简述判断依据或应对办法。 |
| 其他要求 | 按模板补充目的、步骤、思考题或注意事项；不默认另加正式报告的全部章节。 |

综述沿“原理—可观察量—计划操作—计算目标量”的关系展开，不逐页复述课件或抄写完整操作手册。重点说明要学会什么，难点说明哪里容易做错及如何判断，不把同一段换词重复三遍。

公式说明符号、单位与适用条件，写清从读数到结果的必要关系。仪器接线、通道对应、档位、测量组数及位置判据从当前课件核对，不套用其他实验的设置。资料相互矛盾时先定位差异，在交付说明中提出待核对项，同时完成可确定的部分。

## 保持实验前的视角

物理规律用一般陈述，操作写为准备采用的方法，预期现象注明为理论预期。没有本次实测记录时，不写“测得”“观察到”或“结果表明”，不把参考值、课件示例、理想示意图写成已完成实验的证据。

预习可说明拟记录的量、数据处理公式和主要误差来源，不计算本次实测结果、数值不确定度或误差结论。只要求预习报告时，不因缺少数据插入空白结果表或待补的正式报告章节；教师要求预制记录表时，提供带单位的空表。

以学生理解和计划操作为主，使用自然短句，不写“用户未提供”“本报告暂留”等编辑说明。保持主技能的简洁写作规则；需要的推导、接线图和判据不能为压缩篇幅而省略。

## 检查与交付

1. 对照资料核验每项实验的核心原理、公式、方法和操作条件；核验各栏内容是否完整且没有重复或占位文字。
2. 逐栏检查字数。优先按教师规定的计数口径；未规定时，统计渲染后的正文可见字符，去掉空白，不计标题、封面、注释和 Typst 命令，公式与图表是否计入在交付说明中简短注明。不能直接用整个 `.typ` 源码长度或英文单词数代替中文字数，接近上限时留出余量。
3. 只要求源文件时，用新目录编译 PNG 并逐页核验封面、中文字体、公式、图表和分页，交付可编辑 `.typ`；不创建或更新 PDF。
4. 明确要求导出 PDF 时，按项目约定输出到预习报告目录（通常为 `preview/`），使用本次已确认的元数据命名，并检查实际 PDF。只要求评阅时返回问题与依据，不擅自改写或导出。
